Qué hace esta web

Es una página estática de entretenimiento. No hay registro de usuarios ni formularios que envíen datos a un servidor propio.

Estadísticas de visitas

Si está activado en el despliegue, se usa un servicio externo de analítica (por ejemplo Cloudflare Web Analytics, Plausible o Google Analytics) para contar visitas de forma agregada: páginas vistas, país aproximado, dispositivo, origen del enlace.

Los datos los trata el proveedor elegido según su política de privacidad. Chimeno Software no vende listas de visitantes.
